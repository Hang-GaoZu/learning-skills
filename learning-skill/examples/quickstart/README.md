# 最小 Markdown 课程示例

这套文件展示原版 `learning-skill` 的课程结构与主动学习节拍，当前位于“第 1 步尚未完成验收”的状态。

使用时把整个 `quickstart` 目录复制到用户指定的位置，再开始教学；不要直接修改技能目录里的示例来记录真实进度。

文件关系：

- 从 `course-state.md` 恢复进度、学习看板和复习队列，再找到其他文档；
- `steps/第01步.md` 是教学蓝本，含“先预测 → 双轨走查 → 即时反馈 → 变式迁移”；
- 主笔记记录学习看板、累计比喻地图、进度和浓缩正文；
- 自测题先作答后评阅，题目与判定要点分开；
- 两个卡片文件按 `卡片 N` 对应；源文档放完整代码，打字文档只留编号和空代码块；
- 第 3 步文件是当前学到第 1 步时准备的 N+2 草稿。

## 主动学习怎么读

1. 先看主笔记的“学习骨架”和“学习看板”，知道当前在哪、下一步做什么。
2. 进入步骤文档，先回答“先预测”里的问题；不要先看双轨表。
3. 按双轨表逐拍核对：比喻状态、代码动作、变量或输出是否对得上。
4. 对照“即时反馈”判断自己错在哪个关系；错了就按错误类型记录。
5. 做“变式迁移”，再进入自测题完成出口验收。
