# 自测题（示例）

## 第 1 步：查看仓库状态

学完再答，先不查看教学文档。

1. **应用题**：你在 `git add notes.txt` 之后又修改了 `notes.txt`。运行 `git status` 时，`notes.txt` 会出现在哪些区域？这两处分别代表哪个版本？下一次 `git commit` 会提交哪个版本？
2. **旧步复习**：本课程第 1 步没有旧步；从第 2 步开始，此处必须加入旧步复习题。

> 此处只放题目。作答后再根据教学文档评阅并记录到 `course-state.md`。

## 判定要点（作答后再看）

1. 同一文件可能同时出现在“已暂存”和“未暂存”两处；已暂存的是 `add` 时的版本，未暂存的是之后的修改；下一次提交只带已暂存版本。
2. 若把两处混为“文件被修改了两次”，说明边界条件未分清；若只说“文件改了”但说不出提交哪个版本，说明概念混淆。
