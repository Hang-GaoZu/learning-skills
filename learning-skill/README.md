# learning-skill

用于连续推进一对一结构化课程的 Markdown 教学技能。它把每一步组织成可参与的学习循环：先预测、双轨走查、即时反馈、变式迁移，再配合出口验收与错题回收，并维护主笔记、自测题、各步教学文档、源/打字记忆卡片、学习看板和 `course-state.md`。

本版本不生成 HTML 站点，也不要求 JSON 状态；课程文档继续使用 Markdown 和 Mermaid，适合在 Typora 中阅读。

## 学习思路

借鉴动态课程“可视化 + 可操作 + 即时反馈”的体验，但不搬 HTML 实现，而是用 Markdown 能稳定表达的方式达到同样效果：

- **先激活后讲解**：开讲先用一句问题调出旧知，再给新内容；
- **先预测后揭示**：每个核心概念先让用户猜下一状态/下一行/结果，答完再展示；
- **双轨走查**：用状态表或追踪表把“比喻世界状态 ↔ 代码/流程 ↔ 变量或输出”对齐，一次只推进一个可观察状态；
- **即时反馈**：用户作答后立即判定一句话，答错即归类进复习队列；
- **变式迁移**：改变一个条件/参数/场景，让用户预测模型是否仍成立、代码要改哪里；
- **学习看板**：用 6 行摘要显示推进、掌握度、待复习、当前步、下一步建议、下一里程碑。

卡片练习采用“看源文档、在空白页默写”的方式：打字文档只保留编号和空代码块，不提供挖空结构，要求用户回忆完整代码顺序与命名。

## 已保留的教学规则

- 七要素教学与跨步累进比喻地图；
- 源文档、打字文档两个独立卡片文件：源文档存完整代码，打字文档是只含编号和空代码块的空白默写版；
- 应用题与旧步复习题组成的出口验收；
- “验 → 诊 → 补 → 复”和错题回收；
- 知识点依赖顺序与标注式前向引用；
- 第 N+2 步大纲和卡片草稿；
- 轻答疑、只解释不改文件、会了直接过等边界。

## 开始或恢复课程

1. 找到课程目录中的 `course-state.md`。没有状态文件时，先确认用户希望使用的课程目录，再创建。
2. 按 `references/course-files.md` 中的最小模板维护状态与学习看板，路径可沿用用户既有命名。
3. 对新会话可以直接说：

```text
使用 learning-skill，读取 <课程目录>/course-state.md，按老规矩继续。
```

4. 若旧状态字段缺失、路径失效或不同文档互相矛盾，先恢复和核对，不要直接推进新步。

## 最小示例

`examples/quickstart` 展示一套尚未完成第 1 步验收的 Markdown 课程，包含：

- `course-state.md`（含学习看板）；
- `主笔记.md` 与 `自测题.md`；
- 独立的源卡片和空白打字卡片；
- `steps/第01步.md`，含先预测、双轨走查表与变式迁移；
- 第 3 步的 N+2 大纲与卡片草稿。

示例用于说明文件之间的关系和学习循环如何落成 Markdown。实际使用时复制到用户指定的课程目录后再修改，不要把真实学习进度写回技能示例。

## 交付检查

每次推进后按 `references/delivery-checklist.md` 检查主动学习闭环、单步产物和跨文件一致性。尤其注意：

- 文档存在不等于已经掌握；
- 每个核心概念都要有一次用户参与的动作和即时反馈；
- 学习看板的数字要能由验收记录和复习队列算出；
- 当前步、主笔记和验收记录必须一致；
- 打字卡片必须整张空白，不能给代码片段、结构提示或答案；
- 复习队列和 N+2 草稿必须反映最新验收结果。
