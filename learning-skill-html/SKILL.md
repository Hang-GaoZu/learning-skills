# HTML 动态课程

把原有导师式教学升级为 HTML 优先的离线课程站点。保留七要素教学、两件套卡片、出口验收、错题回收、依赖链和 N+2 备课；所有学习者可见文档都有独立 HTML 页面，首页按类别提供不同入口按钮，并用自动计算的“学习概况”展示整体推进与掌握度。

## 开始前

1. 找到并读取课程状态。优先查找 `course-state.json` 或 `course-state.md`；找不到就先问用户课程目录，不从记忆猜测。若只有 Markdown 状态，或旧 JSON 缺少 `steps`，先按 [references/course-state-migration.md](references/course-state-migration.md) 迁移，不静默补猜进度。
2. 完整读取 [references/teaching-rules.md](references/teaching-rules.md)，按原版规则摸底、讲解、验收和复习。
3. 要创建或修改课程站点时，读取 [references/html-course-spec.md](references/html-course-spec.md)。
4. 用户明确说“只解释、不要改文件”时立即退回纯文本答疑，不生成或修改站点。

## 不可省略的学习闭环

- 每步覆盖七要素：目标、核心概念、生活类比、代码或流程解释、常见错误、练习与出口验收、总结。
- 每步交付源卡片与打字卡片两个独立页面；编号和顺序对应，打字页是**空白默写页**，只给编号和空白输入区，不提供代码片段、占位符或答案。
- 开讲前展示学习骨架和累进比喻地图；新概念优先加入已有比喻世界。
- 每次验收至少一道应用题和一道旧步复习题。先让用户作答，再给答案和判定。
- 每次推进更新主笔记、自测、步骤页、卡片、课程状态和复习队列。
- 学会第 N 步时准备第 N+2 步的大纲和卡片草稿；若本步未通过验收，N+2 草稿标记失效。
- 单次正文保持 1-3 页的阅读量。用户说“停止”后立即停止。

## 站点结构

课程源目录建议如下：

```text
course-site-source/
├── course.json
├── course-state.json
└── content/
    ├── notes.html
    ├── self-test.html
    ├── step-01.html
    ├── step-02.html
    ├── cards-source.html
    ├── cards-typing.html
    ├── learning-overview.html
    ├── course-state.html
    ├── next-outline.html
    └── assets/
```

`course.json` 是导航清单，`content/*.html` 是各文档正文片段。生成器会创建独立页面、公共样式、交互脚本和入口总览。不要把所有内容塞进一个超长 HTML。首页优先显示当前任务和常用资料；在 `groups` 中把低频分组设为 `"display": "collapsed"`，让完整入口按需展开。

每类文档使用独立页面和不同入口按钮，至少覆盖：

| 类别 | 入口按钮示例 |
|---|---|
| 主笔记 | 进入主笔记 |
| 各步教学 | 学习第 N 步 |
| 自测题 | 开始自测 |
| 卡片源文档 | 查看源卡片 |
| 卡片打字文档 | 打开打字练习 |
| 课程主线 | 打开课程主线 |
| 课程状态 | 查看进度与复习 |
| N+2 备课 | 查看下一阶段草稿 |

新增的章节脉络、实验记录、术语表等文档也应各自生成页面和入口，不合并到主笔记按钮中。

## 课程主线

不再设置单独的“学习路线”和“学习概况”两个入口。完整页面使用 `kind: "progress"`，由 `course-state.json` 自动生成，一条从左到右的总线串起所有主节点；展开节点显示分支内容与状态。主界面在当前任务下方显示轻量概况。至少显示：

- 课程推进：已经学过的步骤数 / 总步骤数；
- 验收掌握度：✅ 记 1，🟡 记 0.5，🔴、⏭ 和未学记 0；
- 当前步骤、待复习数量和下一步建议；
- 下一里程碑。

完整主线页还要在节点上标记待复习项、展示分支入口、复习队列、薄弱点和最近验收。进度必须来自状态文件，不能由模型估算或手工填写百分比。`course-state.html` 继续作为详细记录页，不与面向学习者的课程主线合并。

## 每步 HTML 动态演示

每个正式教学步骤至少实现一种真正响应操作的演示，例如：

- 流程播放：逐步高亮数据经过的节点和边。
- 代码追踪：前进、后退、重置，并同步显示当前行、变量和说明。
- 参数实验：滑块或选择器改变输入，输出和边界变化实时可见。
- 状态机：展示条件变化如何导致分支跳转。
- 图形与代码同步：同一动作同时改变图形对象、代码行和变量说明。
- 提交后反馈：用户作答后才显示答案、解释和下一题。

优先使用模板提供的 `duet`（图形与代码双栏）、`flow`、`trace` 和 `quiz` 组件；需要特殊模拟时可以在该步骤正文内写隔离的 CSS 和 JavaScript。演示必须离线可用、可键盘操作、支持窄屏，并尊重 `prefers-reduced-motion`。

## 生成与校验

在课程源目录执行：

```powershell
python <skill-dir>\scripts\build_course_site.py --manifest .\course.json --output .\site
python <skill-dir>\scripts\validate_site.py .\site
```

重新生成时只覆盖由本技能生成的站点。生成器会把源文档中的 `assets/...` 复制到站点的 `assets/course/...`。

生成后必须打开 `site/index.html`，检查：

- 每份文档都有独立按钮，按钮能进入正确页面。
- 当前步骤、上一份、下一份和返回总览的导航可往返。
- 至少一个动态演示按预期变化；测验答案提交前不可见。
- 主界面概况数字与完整概况页一致，并能在状态变更后重新生成。
- 课程主线的每个节点能展开分支，复习标记和当前节点位置正确。
- 桌面与 320px 窄屏均无横向溢出，键盘焦点清楚。
- 页面无外部网络依赖、控制台无错误、相对链接无断链。

## 交付

完成一步后，给用户：

1. `site/index.html` 的绝对路径；
2. 本步新增或修改了哪些文档入口；
3. 本步出口验收题；
4. 一句不超过 15 字的继续确认问句。

课程状态、HTML 正文和卡片源文件共同构成跨会话恢复依据。下次继续时先读状态，再检查现有页面，之后只增量更新相关文档和导航。
