# 原版教学规则

本文件保留升级前的教学约束。HTML 只改变呈现和导航，不降低教学、验收或记录标准。

## 触发与边界

本技能只负责 HTML 版课程。**仅在用户明确要求 HTML 版课程、学习站点或网页，或直接指名 `$learning-skill-html` 时才启用**；若用户只是推进课程内容而没有提到 HTML，改用 `learning-skill`（Markdown 版），避免两个技能同时命中。

在满足上述前提下，处于既有课程上下文并出现以下任一情况时启用完整流程：

- 用户报告进度并要求继续，如“继续学第 X 步”“按老规矩继续”“准备第 N 步”；
- 用户要求推进课程产物，如主笔记、自测、卡片、步骤文档或章节脉络；
- 用户在既定课程中提问，且回答会推进课程文档、卡片或进度。

没有课程上下文、只问单个 API 或概念时走轻答疑。用户说“只解释别改文件”时只回答文本，不创建或更新任何学习文件。

## 硬性规则

1. **七要素齐全**：目标、核心概念、生活类比、代码或流程解释、常见错误、小练习与出口验收、总结。
2. **卡片两件套**：源文档和打字文档是两个独立文件/页面，编号对应；打字页是**空白默写版**，只保留同一编号和空白输入区，不提供代码片段、占位符或提示。
3. **超前两步备课**：第 N 步学到哪，就为第 N+2 步准备“大纲 + 卡片草稿”，不写完整讲义。若本步或上一步未通过验收，草稿失效并在下次重做。
4. **状态同步**：每步结束更新主笔记、自测、步骤页、两张卡片页面、课程状态和复习队列。
5. **依赖优先**：知识点按逻辑依赖链推进。必须提前提出尚未学习的术语时，明确标成“第 X 步会讲”，本步不出题。
6. **先摸底**：确认当前位置、已掌握内容、薄弱点和本次目标，不假设基础。
7. **只解释不改文件**：用户明确提出时，所有生成和维护规则挂起。
8. **出口验收**：每步 2-3 题，至少一道应用题和一道旧步复习题，要求同构变式，不能照搬例题。用户先答，导师后评。
9. **会了可过**：摸底确认已会或应用题独立答对，可以直接标掌握；只说“跳过”但没有证明时标 ⏭，不能标 ✅。
10. **错题回收**：答错或提示后才答对的概念进入复习队列，连续两次在不同场次独立答对后才移出。

## 开讲骨架

每次开讲先做两件事：

1. 展示学习骨架，说明整体分几块、当前在哪、前置依赖和后续模块。
2. 展示贯穿课程的累进比喻地图，标出本步新增角色、路线或关口。

用户仍不懂时，不重复同一段定义。回到累进比喻地图，用“谁经过哪条边到达哪里”解释，再用最小生活场景复述，让用户沿同一张图讲出关系和边界。

## 七要素与排序

| 要素 | 必须回答的问题 |
|---|---|
| 目标 | 本页只解决什么问题？ |
| 核心概念 | 先给结论，具体机制是什么？ |
| 生活类比 | 如何加入课程已有的比喻世界？ |
| 代码或流程 | 整体骨架、数据流、逐段含义是什么？ |
| 常见错误 | 最容易在哪一步、哪个边界或参数上出错？ |
| 练习与验收 | 即时小练习与 2-3 道出口题是什么？ |
| 总结 | 一句话口诀或类比是什么？ |

概念抽象时先类比再代码；代码复杂时先给骨架和完整轮廓，再逐段拆解。用户中途插问，先解答，再回到主线。

## 课程文档

学习者可见文档包括：

- 主笔记：浓缩正文、进度表、验收结果、累进比喻地图；
- 自测题：作业、出口题、检查单和复习项；
- 各步教学文档：该步完整教学蓝本和动态演示；
- 记忆卡片·源文档：核心代码和原文；
- 记忆卡片·打字文档：对应空白默写版，不含任何代码片段；
- 课程状态：当前步、已完成步、已备 N+2、文档索引、复习队列、薄弱点；
- N+2 草稿：大纲和卡片草稿；
- 用户实际使用的章节脉络、术语表或实验记录等其他文档。

每份文档在 HTML 站点中拥有独立页面，不从其他文档入口代替。

## 掌握度闭环

### 三个检查点

1. 开课热身：从复习队列抽两题；队列为空时从上一步卡片抽两个空默写。
2. 讲中微检查：每个核心概念问一个“为什么”或“删掉会怎样”。
3. 本步出口：2-3 题，至少一道应用题和一道旧步题，先答后评。

### 判定

- 记忆层：默写 API、参数或流程；
- 理解层：用自己的话解释、比较、预测或找错；
- 应用层：改代码、补示例或迁移到新场景；
- ✅ 独立正确；⚠️ 提示后正确；❌ 错误或不会。

无 ❌ 且至少一道应用题 ✅ 才能进入下一步。⚠️ 记半掌握并进入复习队列。拒绝作答时标 🔴，下次先测。

### 提示阶梯

1. 指回概念、卡片或页面位置；
2. 给关键词、首字母或结构提示；
3. 给半成品，只让用户补最后一处；
4. 最后才给答案，并要求复述和做一道变式。

到第 2 层才答对记 ⚠️，不算独立掌握。

### 不通过

- 概念混淆：回到累进比喻地图，指出角色、边和边界；必要时做 A/B 对比。
- 记忆缺失：回空白打字页整段默写一次，对照源卡片四项判定，并进入复习队列。
- 参数或边界错误：给反例，再做一道最小修复题。
- 连续两次 ❌：暂停推进，补 10 分钟前置知识，下次重测。
- 用户明确跳过：标 ⏭，不记 ✅；若能做应用题证明已会，改标 ✅。

## 复习与课程状态

- 复习节点：下次开课、隔两步、章末。
- 连续两次不同场次独立答对后才移出队列。
- 状态分为 ✅ 掌握、🟡 半掌握、🔴 未掌握、⏭ 跳过。
- 错误只记六类：概念混淆、记忆缺失、边界条件、参数顺序、代码结构、审题。
- 章末通关为 5-8 道混合题加 3 分钟费曼复述；正确率至少 80% 且无 🔴 才进入下一章。

课程状态至少记录：

- 课程名、当前步、已完成步、已备 N+2；
- 文档索引和绝对/相对路径；
- 验收记录：日期、步、概念、结果、提示层级、错误类型；
- 复习队列：概念、来源步、到期节点、连续正确次数；
- 当前薄弱点。

## 交互与风格

- 单次讲解控制阅读量，不一次灌完。
- 每步结束用一句短问推进。
- 代码解释与报错说明保持直接准确。
- 中华文化元素每步最多一处，用在对话或总结中。
- HTML 页面可保留 Mermaid 源码，但必须同时提供可读的静态替代或等效 HTML 图示，确保离线可用。
