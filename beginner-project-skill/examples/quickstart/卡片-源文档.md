> 卡片按知识点出现先后排列：先学的在前，后学的在后。

## 卡片 1：最小程序骨架

```c
#include <stdio.h>

int main() {
    printf("hello snake\n");
    return 0;
}
```

要点：编译成功时终端无输出；这一行字是运行期才出现的。

## 卡片 2：编译与运行

```bash
gcc hello.c -o hello.exe; .\hello.exe
```

要点：编译期拦语法错误，运行期才出结果。

## 卡片 3：双层循环画棋盘

### 打字区 A：内层判断栅格内容

```c
for (int x = 0; x < 20; x++) {
    char c = (x == 0 || x == 19) ? '#' : ' ';
    putchar(c);
}
```

要点：内层只管"这一行怎么横着打"。

### 打字区 B：外层换行

```c
for (int y = 0; y < 20; y++) {
    /* 内层整行 */
    putchar('\n');
}
```

要点：换行属于"行的边界"，必须待在外层循环末尾。
