## 目标与可见结果

- 目标：棋盘上出现一个受方向键控制的点，按一次键移动一格。
- 可见结果：光标点随按键在格内移动，不越出边框。

## 主要动的层

- **输入层**：读键盘（C 终端需注意 `getch` 与回车缓冲的差别）。
- **状态层**：交点坐标 `px, py`，第一次出现真正的"状态变量"。
- 渲染层：把 `(px, py)` 这一格画成 `@`。

## 数据设计草案

| 数据 | 类型 | 取值范围 | 谁改它 |
|---|---|---|---|
| 点横坐标 | int | 0 ≤ px < 20 | 逻辑层（按键后） |
| 点纵坐标 | int | 0 ≤ py < 20 | 逻辑层（按键后） |
| 方向 | char | `w/a/s/d` | 输入层 |

## 预测题（草稿）

1. 按下 `d` 之后，`px` 变成多少？`py` 变不变？
2. 如果 `px` 已经等于 19，再按 `d`，坐标会变成 20 吗？屏幕会怎样？
3. 坐标改了但屏幕上那个点没动，问题在哪一层？
