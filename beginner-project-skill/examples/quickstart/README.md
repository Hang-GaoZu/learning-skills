# 示例：贪吃蛇（C 语言终端版）

这是一套**已经生成好的产物**，用来说明本技能会留下哪些 Markdown 文档、长什么样。

## 文件一览

| 文件 | 说明 |
|---|---|
| `项目笔记.md` | 目标、构建方式、分层图、里程碑进度表、学习看板 |
| `project-state.md` | 跨会话状态：当前进度、构建与运行方式、能力选项（Git / 注释开关）、备份记录、调试记录、验收记录、复习队列 |
| `steps/第00步-环境自检.md` | 第 0 步：最小程序跑起来 + 构建命令拆解 + 备份就位（示例默认 Git，关闭时改用快照） |
| `steps/第01步-画出棋盘.md` | 第 1 步教学页（导师蓝本，含构建说明与新面孔清单，不含完整实现） |
| `卡片-源文档.md` | 卡片代码原文 |
| `卡片-打字文档.md` | 空白默写版 |
| `N+2-第02步-大纲与卡片草稿.md` | 超前两步的大纲草稿 |

## 怎么读

1. 先看 `项目笔记.md` 的"里程碑进度表"和"学习看板"，那是全景。
2. 再看 `steps/第00步`，体会"环境自检"为什么单独立一步。
3. 然后看 `steps/第01步`，注意"先预测"与"判定要点"之间**隔了一段距离**——文档是导师底稿，不是答案册。
4. 最后看两份卡片，注意打字文档里**只有编号、标题和空代码块**，一个字提示都没有。

## 注意

- 示例里的代码只到"够说明结构"的程度，不是完整可玩版本。
- 示例只演示文档形态；真实授课时，预测题要**先发出去等用户作答**，不要一次性把答案摊开。
